# Replace Supervisor with Bun orchestrator

Supervisor and the three shell helpers (`docker-build.sh`, `docker-run.sh`, `docker-watch.sh`) are removed. The container now runs a TypeScript/Bun entrypoint under `/opt/orchestrator` that handles Git sync, conditional `bun install` + `bun run ci` / `bun run build`, nodemon for `.output/server/index.mjs`, periodic Git polling, and an optional HTTP admin UI (`ADMIN_PORT`, default `9090`). Missing `scripts.ci` now falls through to `scripts.build` so builds cannot stall waiting for `.output` alone.
