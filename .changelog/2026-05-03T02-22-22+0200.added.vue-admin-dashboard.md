# Vue admin dashboard

Replaced the inline HTML dashboard with a Vue 3 + Vite app under `admin-ui/`. Production assets are built to `admin-ui/dist`; Bun serves them from `static/` (`bun run build:admin` locally, multi-stage Docker copy to `/opt/orchestrator/static`). Added `src/static-serve.ts` for safe static files + SPA fallback; if no build exists, a short HTML hint is returned. Added `.dockerignore` to keep `node_modules` out of the build context.
